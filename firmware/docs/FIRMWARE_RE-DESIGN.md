# CH32X035F7P6 ファームウェア設計変更ログ

## ハードウェア制約と解決策
- **ピン数**: TSSOP20 (F7P6) のためリマップが必須。
- **USART2 vs PWM**: PA3 で USART2_RX がデフォルトだが、サーボ PWM と競合する。
  - **解決**: USART2 を 1-Wire Half-Duplex に設定し、RXピンを使用しない構成とする。さらにリマップにより論理的なRXピンを PA5 側へ逃がす（実際には USART4 と共有）。
- **USART4 (UART_B)**: PA5 を 1-Wire TX として使用するため、`AFIO_PCFR1` でリマップを適用。
- **OPA2 vs UART**: PA2 (USART2_TX) と PA5 (USART4_TX) が OPA2 のピンと重なっている。
  - **解決**: OPA2 を内部出力モード (`MODE2=0`) に設定して PA2 を解放し、負入力 (`NSEL2=111`) を切り替えて PA5 を解放。

## ソフトウェア設計
- **時間管理の移行**: `Delay_Ms` (SysTick) との干渉を避けるため、プロジェクト全体の時間管理を `TIM3` (1ms割り込み) に移行。
- **プロトコルスタック**: 全ての UART/USB インターフェースで共通のパーサーを使用し、リングバスを構成。
- **USB PD**: PPS 対応を完了。起動時は必ず 5V で安全を確保。
